# NVDA XTTS v2 Plugin

This repository contains a minimal example of an NVDA synthesizer driver
that uses the [`TTS`](https://github.com/coqui-ai/TTS) library with the
XTTS v2 model to provide Turkish speech output. The code can be found in
`xtts_nvda/synthDrivers/xtts.py`.

This implementation is intentionally simple and serves only as a
starting point for developing a full NVDA add-on. To use it, you will
need to install NVDA on Windows, install the `TTS` Python package, and
provide an XTTS model that supports Turkish.
